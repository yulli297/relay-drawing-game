# 릴레이 그림 그리기 게임 (스파이 모드) - 실행 방법

## 처음 한 번만 하면 되는 것
1. VS Code에서 이 폴더(relay-drawing-game)를 엽니다.
2. 위쪽 메뉴 [Terminal] → [New Terminal]을 눌러 터미널을 엽니다.
3. 터미널에 아래를 입력하고 Enter:
   npm install
   (인터넷이 되는 곳에서 딱 한 번만 하면 됩니다. 필요한 부품을 내려받는 과정이에요.)

## 수업 당일, 게임을 켤 때마다
1. 터미널에 아래를 입력하고 Enter:
   npm start
2. "릴레이 그림 그리기 게임 서버가 켜졌어요!" 메시지가 보이면 성공.
3. 이 PC의 IP 주소를 확인합니다.
   - Windows: 터미널에 cmd 창 하나 더 열어서 ipconfig 입력 → "IPv4 주소" 확인
   - Mac: 터미널에 ifconfig 입력 → en0 항목의 inet 주소 확인
   - 보통 192.168.x.x 같은 모양이에요.
4. 선생님 PC 브라우저에서: http://localhost:3000/teacher.html
5. 학생 패드 브라우저에서: http://(3번에서 확인한 IP주소):3000/student.html
   예) http://192.168.0.15:3000/student.html

## 끝낼 때
- 터미널 창에서 Ctrl + C 를 누르면 서버가 꺼집니다.
- 서버를 끄면 그날의 점수 기록은 사라집니다(다시 켜면 처음부터 시작).

## 제시어를 바꾸고 싶을 때
- server.js 파일 위쪽의 WORD_LIST 부분만 수정하면 됩니다.
- 코드를 몰라도 따옴표 안의 단어만 바꾸면 돼요. 예:
  { real: '경찰차', spy: '구급차' },
- 6줄(6라운드)이 채워져 있어야 합니다.
- 수정 후에는 서버를 껐다 다시 켜야 반영됩니다(Ctrl+C 후 npm start).

## 참고
- 학생/선생님 모두 같은 학교 와이파이에 접속되어 있어야 합니다.
- 서버(선생님 PC)가 켜져 있는 동안에만 학생들이 접속할 수 있습니다.
